# 구마트래블 공항 키워드 페이지 — 제작 준비

키워드 4,893개 중 우선순위 2,000개를 골라, 검색 의도가 같은 것끼리 페이지로 묶었다.

| 파일 | 내용 |
|---|---|
| `keywords/구마트래블_제작_2000.xlsx` | 시트1 키워드 2,000 (각 키워드가 들어갈 페이지 URL·대표 여부·오픈 묶음), 시트2 페이지 목록 |
| `seo/pages.json` | 빌드 입력: 페이지 id·유형·공항·장소·방향·의도·대표 키워드·보조 키워드 |

## 선정 기준

- 점수 = 출처(실제 검색어 300 · 패턴 조합 100 · 서비스 조합 80) + 우선순위(1=200, 2=100) + 자동완성 등장 수×20 + 최고 순위 보정
- 버스·전철 시간표만 찾는 1회성 검색(대중교통 비교, 등장 1회)은 제외
- 결과: 실제 검색어 1,613 · 패턴 조합 368 · 서비스 조합 19

## 왜 2,000페이지가 아니라 111페이지인가

"仁川空港 明洞 タクシー 料金 / いくら / 値段", "明洞 / ミョンドン" 은 같은 사람이 같은 답을 찾는 검색이다. 키워드마다 페이지를 만들면 거의 같은 페이지가 수십 장씩 생기고, 구글은 이를 도어웨이(양산형)로 보고 사이트 전체 순위를 내린다. 그래서 **한 페이지 = 한 검색 의도**, 변형 키워드는 그 페이지의 제목·소제목·FAQ에 녹인다.

| 묶는 단위 | 예 |
|---|---|
| 공항 + 지역 + 방향 + 의도 | `/icn-myeongdong-taxi` 仁川空港→明洞 タクシー・送迎 |
| 의도 2갈래 (지역 경로) | taxi = 택시·픽업(차로 가기) · ikikata = 가는 법·버스·전철 비교 |
| 방향 | 입국 `/icn-gangnam-taxi` · 출국 `/gangnam-to-icn-taxi` |
| 공항 단독 상황 | `/icn-shinya` 심야 도착 · `/icn-soucho` 새벽 · `/icn-terminal` 터미널 이동 · `/icn-hotel` 공항 호텔 · `/icn-nimotsu` 짐 배송 |
| 공항↔공항 | `/icn-gmp-transfer` |

결과: 신규 107페이지 + 기존 랜딩 4곳(메인·seoul-sougei·seoul-charter·incheon-airport-sougei)에 보조 키워드 배정.

| 의도 | 페이지 |
|---|---|
| 가는 법(ikikata) | 45 |
| 택시·픽업(taxi) | 39 |
| 짐 배송(nimotsu) | 10 |
| 공항 단독 상황(shinya·soucho·terminal·hotel·kotsu·sougei) | 13 |

## 페이지 구성 (일본어, 지역 경로 페이지 기준)

1. **H1** = 대표 키워드를 자연문으로 (`仁川空港から明洞へタクシーでいくら？定額送迎との比較`)
2. **要点まとめ 박스** — 거리 55.6km · 차로 약 55분(目安) · 구마트래블 정액 150,000ウォン(車1台) · 심야도 같은 요금 여부
3. **비교표** — タクシー / リムジンバス / 空港鉄道(AREX) / クマトラベル: 요금·시간·짐·심야·일본어
4. **상황별 소제목** — 보조 키워드에서 뽑는다 (深夜到着なら / 子連れ・大人数なら / 荷物が多いなら / 予約方法)
5. **도착 후 흐름** — 입국장 이름표 출迎 → 짐 → 차량 → 호텔 (공항·터미널마다 다른 만남 장소)
6. **FAQ 4~6개** — 보조 키워드의 질문형(いくら·何分·乗り場どこ·安全)
7. **관련 페이지 링크** — 같은 지역 반대 방향, 같은 지역 다른 의도, 같은 공항 이웃 지역 6곳
8. **CTA** — LINE·전화·문의 폼 (기존 메인과 동일)
9. JSON-LD: BreadcrumbList · FAQPage · Service(Offer 가격) · ItemList(관련 페이지)

페이지마다 다른 사실: 거리·시간(places.json), 대표 지점, 공항별 만남 장소, 지역 특징 한 줄(숙소 많은 곳·쇼핑 등), 보조 키워드 FAQ. 문장 틀은 슬러그 해시로 여러 벌 중 고정 선택.
배포 전 기준: 본문 1,300자 이상, 샘플 쌍 유사도 평균 0.5 미만 (`programmatic-seo/scripts/pseo_lint.py`).
